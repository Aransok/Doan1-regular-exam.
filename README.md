# Cookbook

A recipe management web app built as a regular exam project — browse, add, and manage cookbook recipes through a server-rendered MVC interface.

## Tech Stack
- Node.js + Express
- Pug templating
- node-fetch for external requests

## Testing
- Unit tests: Mocha (`npm run test:unit`)
- UI/e2e tests: Playwright (`npm run test:ui`)

## Getting Started
```bash
npm install
npm start
```
